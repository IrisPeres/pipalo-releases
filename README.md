# Pipalo

Meet Pip, your pal: a small desktop pet for macOS that shows your Claude Code usage and gives kind wellbeing reminders (water, posture, eyes, breaks).

This repository holds **downloads, release notes and feedback** for Pipalo. The app's source code is not published here.

## Status
Pre-release. Signed downloads and `brew install --cask` are coming. Until then there is nothing to install from here.

## Privacy
Pipalo has no account, no telemetry and no server of ours. It reads local files and your own tools on your Mac, each behind a switch you control.

## Feedback
Found a bug or have an idea? [Open an issue](../../issues/new). Please do not paste tokens, customer data or anything private.
